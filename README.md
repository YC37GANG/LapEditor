# 🛠️ YC37 Gang — Lap Editor

เครื่องมือแก้ไขข้อมูล Lap โดยตรง (เวลาเริ่ม/ปิด + ค่า YC) ผ่านหน้าเว็บที่ใช้งานง่ายทั้งมือถือและคอม — สร้างขึ้นมาแทนการเข้าไปแก้ผ่าน Firebase Console ที่ใช้งานลำบากบนมือถือ (ปุ่มบันทึกกด Enter ไม่ได้, ต้องคลิกขยาย ▶ หลายชั้น)

**ใช้คู่กับ**: [YC37 Gang Counter Dashboard](../) (เว็บหลัก) และ [Firmware](../firmware/) (ฮาร์ดแวร์)

---

## ✨ ฟีเจอร์

- 🔍 **ค้นหา Lap แบบพิมพ์กรองสด** — ค้นได้ทั้งเลข Lap, วันที่, หรือเลข YC ในช่องเดียว
- 🎯 **ค้นหาแบบเจาะจง** — พิมพ์คำนำหน้าเพื่อค้นตรงเป๊ะ:
  - `ยา5` หรือ `yc5` → หา Lap ที่มีค่า YC ตรงกับ 5 เท่านั้น
  - `lap5` หรือ `l5` → หา Lap หมายเลข 5 เท่านั้น (ไม่ปนกับ lap15, lap51)
  - พิมพ์อย่างอื่น → ค้นหาแบบกว้าง (จับคู่ได้ทั้งเลข Lap/วันที่/YC)
- 🕐 **แก้เวลาเริ่ม/ปิดผ่านปฏิทินสัมผัส** — ใช้ตัวเลือกวันที่-เวลาของเครื่องเอง แต่แสดงผลเป็น `dd/mm/yyyy` แบบ 24 ชม. เสมอ ไม่ขึ้นกับภาษา/locale ของเครื่องแต่ละคน
- 💊 **แก้ค่า YC ทั้ง 2 ช่องพร้อมกัน** — combobox เลือกเลข 1-10 แบบเดียวกับเว็บหลัก
- 🔄 **ลบเวลาปิด** — ทำให้ Lap กลับเป็นสถานะ live ได้ในคลิกเดียว
- 🔒 **ด่านรหัสผ่านก่อนเข้าใช้งาน** — กันคนไม่ตั้งใจเข้ามาเจอ (ดูข้อจำกัดด้านล่าง)

## 🔑 ตั้งรหัสผ่าน

เปิดไฟล์หาบรรทัดนี้แล้วแก้ข้อความในเครื่องหมายคำพูด:
```js
const EDITOR_PASSWORD = "1234yc37";
```

> ⚠️ **นี่คือการเช็คฝั่งหน้าเว็บ (client-side) เท่านั้น ไม่ใช่ระบบความปลอดภัยจริงจัง** — รหัสผ่านฝังอยู่ในโค้ดที่ใครก็เปิดดูได้ (View Page Source) เหมาะแค่กันคนไม่ตั้งใจเข้ามาเจอ ไม่ใช่กันคนที่ตั้งใจเจาะระบบ เหมาะสำหรับใช้ในกลุ่มเพื่อนที่ไว้ใจกันเท่านั้น

รหัสผ่านที่ใส่ถูกจะจำไว้แค่ **ระหว่าง session เดียว** (ปิดแท็บ/เบราว์เซอร์แล้วต้องกรอกใหม่)

## 🗄️ ตั้งค่า Firebase Rules ที่จำเป็น

เครื่องมือนี้เขียนข้อมูลลง 2 path — ต้องเปิดสิทธิ์เขียนไว้ทั้งคู่ใน **Firebase Console → Realtime Database → Rules**:

```json
{
  "rules": {
    ".read": true,
    ".write": false,
    "kratom_notes": { ".write": true },
    "kratom_yc": { ".write": true },
    "kratom_lap_index": { ".write": true },
    "kratom_laps": { ".write": true }
  }
}
```

> ⚠️ เปิดสิทธิ์เขียนแบบนี้แปลว่าใครก็ตามที่รู้ URL ของ Database เดียวกันเขียนทับข้อมูลได้โดยตรง — เหมาะกับกลุ่มเพื่อนที่ไว้ใจกันอยู่แล้วเท่านั้น เช่นเดียวกับ path อื่นที่เปิดไว้ก่อนหน้า

## 🚀 วิธีใช้งาน

1. เปิดไฟล์นี้จากมือถือหรือคอมก็ได้เหมือนกัน
2. กรอกรหัสผ่าน
3. พิมพ์ค้นหา Lap ที่ต้องการแก้
4. แตะเลือกจาก dropdown ที่กรองมาให้
5. แตะช่องเวลาเริ่ม/ปิด → เลือกจากปฏิทินที่เด้งขึ้นมา
6. เลือกค่า YC (หรือเว้นว่างได้ถ้าไม่มี)
7. กด **บันทึกการแก้ไข** — บันทึกทั้งเวลาและ YC พร้อมกันในคลิกเดียว

## ⚠️ ข้อจำกัดที่รู้อยู่แล้ว

- ต้องมีเน็ตตลอดเวลาที่ใช้งาน (ดึง/เขียนข้อมูลผ่าน Firebase โดยตรง ไม่มีโหมด offline)
- รหัสผ่านเป็นการป้องกันระดับพื้นฐานเท่านั้น (ดูหัวข้อด้านบน)
- ปฏิทินตอนกำลังเลือก (native picker) อาจแสดงเป็น 12 ชม. AM/PM ถ้าเครื่องตั้ง locale แบบนั้น — เป็นข้อจำกัดของเบราว์เซอร์ที่ควบคุมไม่ได้ แต่**ผลลัพธ์ที่บันทึกและแสดงผลจริงเป็น 24 ชม. เสมอ**
